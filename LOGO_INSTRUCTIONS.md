# Logo Installation Instructions

## 🚨 IMPORTANT: How to Add Your AmritGamerog Logo

### Step 1: Save Your Logo
1. Save your AmritGamerog logo image as: `amritgamerog-logo.png`
2. Place it in: `c:\Users\Acer\Desktop\portfolio\assets\amritgamerog-logo.png`

### Step 2: Create the Assets Folder (if needed)
If the `assets` folder doesn't exist:
1. Create a new folder called `assets` in your portfolio directory
2. Place the logo file inside this folder

### Current Fallback System
Until you add the logo image, the site will show:
- 👑 Crown emoji as a temporary logo
- All "Amrit Yadav" text has neon glow effects
- Responsive design maintained

### Logo Specifications
- **Format**: PNG (preferred) or JPG
- **Size**: 120-200px width recommended
- **Background**: Transparent PNG works best
- **File name**: Must be exactly `amritgamerog-logo.png`

### File Structure Should Look Like:
```
portfolio/
├── assets/
│   └── amritgamerog-logo.png  ← Your logo here
├── index.html
├── styles.css
├── script.js
└── README.md
```

- All "Amrit Yadav" text now has cyan neon glow
- Logo will have neon effects when loaded

- Responsive across all devices
